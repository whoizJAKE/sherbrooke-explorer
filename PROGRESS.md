# Sherbrooke Explorer — progress

## Final report

Sherbrooke Explorer is a third-person (first-person with V) walk-and-drive reconstruction of Sherbrooke, Québec, at about 1 meter per unit.

**Play in the browser:** https://jacobhmaiddout.com/sherbrooke-explorer/

**Source:** https://github.com/whoizJAKE/sherbrooke-explorer

`https://whoizjake.github.io/sherbrooke-explorer/` redirects there, because the account site uses the custom domain jacobhmaiddout.com.

### Performance

On this Mac the packaged arm64 app and the public site both bring up downtown with the HUD visible. The view draws about **176 calls and 30,000 triangles**. An uncapped loop of the real frame function in the packaged app finished a frame in about **0.6 ms** (well above 60 fps). The display refresh rate is what will cap it. Chunks outside the camera are not drawn.

### Run it from a clean checkout

```bash
git clone https://github.com/whoizJAKE/sherbrooke-explorer.git
cd sherbrooke-explorer
npm install
npm run dev
```

Open http://localhost:5173 and click the view to look around.

Native app (unsigned):

```bash
npm run build:mac
```

Open the `.dmg` in `release/`, drag Sherbrooke Explorer to Applications, then control-click the app and choose Open the first time. F11 is fullscreen. `npm run dev:electron` runs the same window against the Vite dev server.

### Visual upgrade, 2026-09-23

Daytime downtown Rue King and the Pont Jacques-Cartier approach were the comparison views. The same spawn camera was used before and after.

What changed in the running game:

- Roads are resampled onto the terrain so a hill no longer cuts through the asphalt. A street corridor has the small noise removed, so the carriageway stays seated. Sidewalks sit a few centimetres below the asphalt. Quebec-style markings are separate geometry: double yellow on primary roads, a dashed yellow centre line on other streets, white edge lines.
- Bridge ways clear the water by a fixed rule (at least 3.6 m over the river surface, or 4.5 m when the way is an overpass with no water under it). The ends blend back to the ground. The deck has parapets, a concrete soffit, and piers where the centreline is over water. That clearance is not a surveyed deck elevation.
- Building walls follow the slope at the base and keep a level roof. Commercial footprints get a glass ground floor. A dark door is placed on the longest street-facing wall of smaller buildings. Trees are skipped on roads, on water, and inside footprints.
- Lighting is a daytime sun with a shadow map that follows the player on the high preset, a softer sky, and fog that matches the horizon. The river shader is a dark green Magog colour with a small sun glint, not a mirror. Q switches to a low preset with shadows off.
- Cars use a clearer body, glass, and wheels. The driving camera stays closer, and steering eases off as speed rises. The interface has an English and French string table. The FR/EN button is in the corner.
- Surface textures and tree cards are generated by `scripts/make-textures.mjs`. The earlier photo-like images had no recorded licence, so they were removed.

Checked on this Mac in headless Chrome:

- Movement self-test passed (WASD and arrows).
- A two-second throttle moved the downtown car 20.7 m.
- High preset, downtown: 252 draw calls and 62,171 triangles. The previous downtown view was about 176 calls and 30,000 triangles. A real frame time was not measured: headless virtual time reported an infinite frame rate, so that number is not used.
- `npm run build:web` succeeded. Serving `dist/` at `/sherbrooke-explorer/` loaded `world.pack` (1.8 MB) and the textures. `?lang=fr` showed the French hint and “Lieux”.
- The macOS installer was not rebuilt. Electron still loads `dist/index.html` with the same relative asset paths.

### Known limits

- Rock Forest's center (about longitude -71.99) sits just west of the requested bounding box. The landmark is on the eastern part of Rock Forest that the box does include.
- Buildings with no height in OpenStreetMap use 2–8 floors. Large downtown offices and named towers use 15–25. That rule is not a survey of real floor counts. Façades are generated window grids on the real footprint, not measured architecture.
- Physics boxes follow each footprint's bounding box, so the notch of an L-shaped building is solid.
- `public/audio/city-ambient.wav` and `public/audio/rain.wav` are synthesized loops, not field recordings. The engine note is generated while you drive.
- The character is still a simple figure. Cars are clearer than the first boxes, and they are not a vehicle catalogue.
- Road joins at intersections can still show a seam or a short stray marking. There is no moving traffic.
- Bridge deck height is the rule above, not a city survey.
- The macOS app is unsigned and not notarized, and the 2026-09-23 installer was not rebuilt.
- GitHub rejected the push of `.github/workflows/deploy.yml` because the signed-in token has `repo` scope and not `workflow`. The file is on disk. The public site is the `gh-pages` branch instead, and that URL was loaded in a browser through to a running city (same draw-call count as the local build). To turn on the Action later: `gh auth refresh -h github.com -s workflow`, commit `.github/workflows/deploy.yml`, push, then set the repo's Pages source to GitHub Actions.

### Suggested next steps

- Refresh the GitHub token and publish the Actions workflow so every push to `main` rebuilds the site.
- Extend the map west to about -72.02 so all of Rock Forest is inside.
- Replace the synthesized audio with recordings from downtown and the campuses.
- Use surveyed heights for the towers along King and Wellington.
- Add a bit of traffic, and interiors for the cathedral, the Granada, and the market.
